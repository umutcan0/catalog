Catalog - A Modern Catalog Management System

Welcome to Catalog! This robust and scalable catalog management system, developed using Java Spring Boot, provides a structured backend architecture to efficiently manage operations 
such as adding, updating, deleting, and retrieving catalog items.

🚀 Features

📦 Catalog Management - Add, update, delete, and retrieve catalog items

🛠 Modular Architecture - Clean and well-organized code structure

📜 Custom Exception Handling - Better error management with custom exceptions

📊 DTO Implementation - Layered structure using Data Transfer Objects

🔍 Repository Pattern - Efficient data access with JPA repositories

🔄 Service Layer - Business logic encapsulated in a dedicated layer

🧪 Comprehensive Testing - Unit and integration tests for reliability


📁 Project Structure

Catalog  
│── advice          # Custom exception handling and global error handling  
│── controller      # REST API controllers handling client requests  
│── dto            # Data Transfer Objects for structured data management  
│── entity         # JPA entities representing database models  
│── exception      # Custom exceptions for better error handling  
│── repository     # JPA repositories for database operations  
│── service        # Business logic layer implementing core functionalities  
│── test           # Unit and integration tests for ensuring reliability  


🛠 Technologies Used

Java 17

│── Spring Boot (Spring Web, Spring Data JPA, Spring Validation)

│── Hibernate (JPA)

│── H2 Database / PostgreSQL

│── Lombok

│── Swagger (API Documentation)

│── JUnit & Mockito (Testing)


🏗 Setup and Run

1️⃣ Clone the repository:

 git clone https://github.com/yourusername/catalog.git

2️⃣ Navigate to the project directory:

 cd catalog

3️⃣ Run the application using Maven:

 mvn spring-boot:run

4️⃣ Access API Documentation (Swagger UI):

 http://localhost:8080/swagger-ui.html
